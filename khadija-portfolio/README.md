# Khadija's Personal Portfolio

A responsive multi-page student portfolio built with HTML, CSS, and vanilla JavaScript for SITE 1101.

## Pages
- `index.html` — Home
- `about.html` — Academic interests and hobbies
- `projects.html` — Project 1 plus placeholders for Projects 2 and 3
- `memories.html` — University life photo gallery
- `game.html` — Interactive Movie & Math Multiverse

## Run locally
Open the folder in VS Code. Install the **Live Server** extension if desired, then right-click `index.html` and choose **Open with Live Server**. The site also works as a static website.

## Before publishing
1. Replace `YOUR-USERNAME/YOUR-REPOSITORY` in every HTML footer with your GitHub username and repository name.
2. Add your Minecraft photo as `images/minecraft.jpg` and update the placeholder in `about.html` if you want it displayed.
3. Complete the Project 2 and Project 3 descriptions and add genuine screenshots/photos.
4. Check every image and link, then test the site on desktop and mobile.
5. Keep your own AI development conversation and export the complete conversation as Markdown, as required by the course instructions.

## GitHub Pages
In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. Your website will be published at `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/` (or the root user-site URL if this is your user-site repository).
